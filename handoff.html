Schema Supabase

players popolata

Fonte: nba2kapi.com bulk. Aggiornare con node scripts/seed.mjs (senza flag).

slug        text PRIMARY KEY
data        jsonb  -- full player object
updated_at  timestamptz
player_potentials popolata

Fonte: 2kratings.com (potentials) + basketball-reference (età fallback). 555 record con età.

slug        text PRIMARY KEY
potential   text   -- A+/A/A-/B+/B/B-/C+/C/D
age         integer
updated_at  timestamptz
contracts popolata

Fonte: basketball-reference contracts page. 460 contratti. Colonna age aggiunta manualmente.

name            text PRIMARY KEY
team            text
age             integer
salaries        jsonb  -- [{year, amount, note}]
years_remaining integer
updated_at      timestamptz
saved_players attiva

Roster personale per utente. RLS: ogni utente vede solo le proprie righe.

user_id     uuid REFERENCES auth.users
slug        text
player_data jsonb
PRIMARY KEY (user_id, slug)
SQL richiesto una tantum: ALTER TABLE contracts ADD COLUMN IF NOT EXISTS age integer; — già eseguito sul progetto corrente.

Seed Script

File: scripts/seed.mjs. Usa SUPABASE_SERVICE_ROLE_KEY per bypassare RLS.

$ node scripts/seed.mjsFull seed: players + potentials + contratti + età
$ node scripts/seed.mjs --contracts-onlySolo contratti da basketball-reference
$ node scripts/seed.mjs --ages-onlyEtà da 2kratings + bbref fallback (~20-30 min)
$ node scripts/seed.mjs --diag=luka-doncicDebug estrazione HTML su singolo giocatore

Note scraping età

2kratings.com espone Birthdate: September 15, 1999 nell'HTML. Cloudflare blocca richieste singole fredde (come il diagnostico) ma non il seed completo che usa browser context con concurrency 5 e user-agent reale. Le 555 età attuali vengono da bbref NBA_2026_per_game.html (stagione 2025-26 completata) e sono accurate. Per aggiornare con date precise da 2kratings, lanciare --ages-only.

Player Scorer

Ogni giocatore riceve 4 sub-score 0–100 calcolati in lib/nba/playerScorer.ts. Il total è la media pesata dagli slider dell'utente.

DimensioneInputFormula chiave
REBUILDage, potentialageScore(age)×0.55 + potScore×0.45. null age → 5 (penalizzato)
WIN NOWoverallScala da 0 (OVR≤65) a 100 (OVR≥95)
VALUE HUNT14 attributi chiave vs overallSomma di max(0, attr−(OVR−3)) per attributi ≥75, normalizzata
TEAM FRIENDLYyears_remaining, salary, noteyearsScore×0.45 + salaryScore×0.55 ± optionBonus

Attributi usati per VALUE HUNT: threePointShot, drivingDunk, closeShot, drivingLayup, speed, agility, vertical, strength, steal, block, perimeterDefense, ballHandle, passIQ, speedWithBall.

Bug noti

Filtro posizione Draft Builder non funziona bug

Il filtro PG/SG/SF/PF/C nell'header del Draft Builder non filtra correttamente la lista. Il posFilter state esiste e la condizione p.positions.includes(posFilter) è nel memo, ma il risultato non viene applicato. Da investigare: possibile problema di dipendenze nel useMemo o il campo positions nell'oggetto player ha una struttura diversa da quella attesa.
